# Lumina Chrome Extension

Injects the "Convert Last Answer" prompt into ChatGPT, Gemini, or Claude and submits it.

## Install

1. Open Chrome → `chrome://extensions`
2. Enable **Developer mode** (top right)
3. Click **Load unpacked**
4. Select this `chrome-extension` folder

## Usage

1. Open a conversation in ChatGPT, Gemini, or Claude
2. Click the ✦ Lumina extension icon
3. Click **Convert Last Answer**

## Supported

- chatgpt.com
- chat.openai.com
- gemini.google.com
- claude.ai

## Note

You need a PNG icon named `icon.png` in this folder.
Convert `icon.svg` to PNG using any tool, or use any 128×128 PNG.
