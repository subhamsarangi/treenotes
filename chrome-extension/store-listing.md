# Chrome Web Store Listing

## Name
Lumina — Convert Last Answer

## Short Description (max 132 chars)
Instantly convert your last AI answer into structured JSON with one click. Works on ChatGPT, Gemini, and Claude.

## Full Description
Lumina is a companion extension for the Lumina knowledge base app.

With one click, it injects a structured prompt into your active AI conversation — asking the model to convert its last answer into a clean JSON format ready to import into Lumina.

**Supported platforms:**
- ChatGPT (chatgpt.com)
- Google Gemini (gemini.google.com)
- Claude (claude.ai)

**How it works:**
1. Have a conversation with any supported AI
2. Click the Lumina extension icon
3. Hit "Convert Last Answer"
4. The prompt is injected and submitted automatically
5. Copy the JSON output and import it into Lumina

**No accounts. No data collection. No permissions beyond the active tab.**
